# Chiang Mai, but slow

Static site, no build step. `index.html` is the colour style, `mono.html` is the monochrome style. To publish on GitHub Pages:
1. Push `index.html` and the `images/` folder to a repo.
2. Settings > Pages > Deploy from branch > `main` / root.
3. Share the `https://<user>.github.io/<repo>/` link.
Travel estimates (distance, time, Grab vs car) use the CONFIG block near the top of the script, so you can edit the numbers.
Add photos in `images/` (see `images/README.md`).
